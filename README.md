# Jesús Gilberto Elías Ogaz — Personal Consulting Website

Premium bilingual (ES/EN) consulting website for Chief Economic Strategist Jesús Gilberto Elías Ogaz.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Locales: `/es` (default) and `/en`

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — middleware redirects to `/es`.

## Content integrity

Biographical facts, case metrics, publications, and speaking dates are **not invented**. Pages that require verified personal data show intentional “pending / under construction” states until you supply authorized content.

Update copy in `src/content/dictionaries.ts`.
